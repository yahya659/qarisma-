---

## 📌 نظرة عامة
**Qarisma** هي منصة محتوى ديناميكية تتيح للمستخدمين تصفح مقالات وأخبار مصنفة ضمن فئات متعددة مثل:

- 🎨 الفن
- 🏥 الصحة
- 👶 الأطفال
- 🎮 الألعاب
- 👗 الموضة
- ⚽ الرياضة
- 👥 الشخصيات الاجتماعية
- 🌿 الطبيعة

- وغيرها...

كل فئة تشترك في نفس واجهة المستخدم مع محتوى مختلف، مما يوفر تجربة متسقة وسهلة الاستخدام.

## ✨ المميزات

- ✅ واجهة موحدة وديناميكية لجميع الفئات
- ✅ تحميل المحتوى بشكل ديناميكي حسب الفئة المختارة
- ✅ تصميم متجاوب (Responsive) يعمل على جميع الأجهزة
- ✅ أداء عالي بفضل Next.js App Router و SSR/SSG
- ✅ كود مكتوب بالكامل بـ TypeScript لضمان الجودة

## 🚀 تشغيل المشروع محلياً

```bash
# 1. استنساخ المشروع
git clone https://github.com/yahya659/qarisma-.git
cd qarisma-

# 2. تثبيت المكتبات
npm install

# 3. تشغيل بيئة التطوير
npm run dev
